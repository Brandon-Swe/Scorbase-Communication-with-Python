Set Subroutine CALC_CELL_POSITION
Remark: Position 110 is the calculated position for the required cell.
Set Variable TEMP  = CELL_NUMBER - 1
If CELL_NUMBER < 37 Jump to CONT2
Set Variable TEMP  = CELL_NUMBER - 37
CONT2:
Set Variable ROW_INDEX  = TEMP \ 6
Set Variable COLUMN_INDEX  = TEMP MOD 6
Set Variable CURRENT_X  = -CELLS_DELTA_X * COLUMN_INDEX
Set Variable CURRENT_Z  = CELLS_DELTA_Z * ROW_INDEX
Teach Position 110 by Joints. Relative to: BASE_POSITION. Coordinates: CURRENT_X CURRENT_Z 0 0 0
Return from Subroutine
